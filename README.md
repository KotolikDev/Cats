## Описание

Интерактивное Android-приложение, которое:

- 🖼 Отображает изображения котов  
- 🔊 Воспроизводит случайные звуки "мяу" при нажатии на кнопки
- 🔤 Меняет текст при каждом нажатии 
- 🛠 Демонстрирует базовые принципы работы с:
  - `ImageView` — для отображения изображений
  - `MediaPlayer` — для воспроизведения звуков
  - `Button` — для взаимодействия
  - `TextView` — для отображения текста
  - Обработкой событий нажатия

---

## Визуальные эффекты

### 🔘 Эффекты кнопок:

1. **Стандартный ripple-эффект**
2. **Кастомная анимация масштабирования:**
   - При нажатии кнопка/изображение немного уменьшается *(scale-эффект)*
   - При отпускании возвращается к исходному размеру

## Иконка приложения

### 📌 Требования к иконке:

#### **Google Play:**
- Размер: **512×512** пикселей
- Формат: **PNG без альфа-канала**
- Уникальный дизайн, не копирующий системные иконки

#### **Material Design:**
- Использует принцип **ключевой формы (key shape)**
- Обеспечивает **контрастность и читаемость**
- Соответствует рекомендациям по **размерам и отступам**
